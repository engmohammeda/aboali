# الكلمات المفتاحية وسيو حراج

## 1) مجموعات الكلمات (Clusters)

**A — نية شراء مباشرة (الأولوية القصوى):**
- سيراميك الرياض
- بورسلان الرياض
- سعر متر السيراميك الرياض
- سيراميك جملة الرياض
- بورسلان أسباني الرياض
- سيراميك حمامات الرياض

**B — حسب الغرفة/الاستخدام:**
- سيراميك أرضيات مجالس
- بلاط مطابخ مقاوم للانزلاق
- بورسلان جدران حمام
- سيراميك خارجي للمداخل
- بلاط مسابح

**C — حسب المقاس:**
- بورسلان 60×120
- سيراميك 60×60
- بورسلان 120×240
- بلاط 30×60 جدران

**D — حسب الخدمة:**
- تركيب سيراميك بالرياض
- معلم بلاط الرياض
- توريد سيراميك للمقاولين
- توصيل سيراميك داخل الرياض

**E — حسب المنشأ/الجودة:**
- بورسلان إسباني
- سيراميك درجة أولى
- سيراميك مقاوم للانزلاق
- بورسلان ضد الخدش

## 2) بنية عنوان إعلان حراج (النموذج)

```
[النوع] + [المقاس] + [المنشأ/الجودة] + [المدينة] + [ميزة/سعر] 
```

**أمثلة جاهزة:**
- `بورسلان 60×120 إسباني درجة أولى — الرياض — أسعار جملة`
- `سيراميك أرضيات 60×60 مقاوم للانزلاق — الرياض — متوفر الآن`
- `بلاط جدران حمامات 30×60 — الرياض — توصيل فوري`
- `توريد سيراميك وبورسلان للمقاولين — الرياض — أسعار كمية`

**قواعد العنوان:**
- 55–70 حرفًا، والكلمة الأهم في الأول.
- لا حروف كبيرة عشوائية، لا رموز زائدة (`!!!!`).
- لا كلمات محظورة أو مبالغة ("أرخص").

## 3) بنية وصف الإعلان (قالب)

```
[سطر 1] الوصف المختصر: ماذا نبيع ولمن.
[سطر 2] المقاسات المتوفرة: ...
[سطر 3] المنشأ والمواصفات: ...
[سطر 4] السعر / ابتداءً من: ...
[سطر 5] التوصيل والتركيب: ...
[سطر 6] الموقع: الرياض — حي ...
[سطر 7] للتواصل: واتساب مباشر + ساعات العمل.
```

## 4) قواعد السيو داخل حراج (مهم)

1. **كرّر الكلمة المفتاحية 2–3 مرات** في العنوان والوصف بشكل طبيعي (لا حشو).
2. **حدّث الإعلان أسبوعيًا** (تعديل بسيط) — يحافظ على الظهور.
3. **أعد نشر الإعلانات المنتهية** بصور جديدة وعنوان محسّن.
4. **أضف صورًا متعددة** (5 صور على الأقل) — يزيد التفاعل والثقة.
5. **اكتب المقاس والمنشأ في الصورة نفسها** — كثير من الزوار لا يقرأ الوصف.
6. **لا تعيد نشر نفس الإعلان عدة مرات** في نفس اليوم (يُستغل كسبام).
7. **اربط الوصف بـ "الرياض" والحي** — يزيد مطابقة البحث المحلي.

## 5) أفكار محتوى للسوشيال (تدعم إعلانات حراج)

- "الفرق بين السيراميك والبورسلان" — فيديو 30 ثانية.
- "كيف تحسب كمية البلاط بنفسك" — منشور تعليمي (نفس الحساب في الإعلانات).
- "قبل وبعد" لحمام مُرمّم.
- "خطأ شائع: بلاط انزلاقي في الحمام".
- "جولة في المخزون" — تحديث أسبوعي.
