# دليل الأصول البصرية

## 1) مجلدات الأصول

| المجلد | ما يوضع فيه | الحالة |
|---|---|---|
| `الشعار/` | شعار SVG + PNG شفاف (أفقي/مربع/أحادي اللون) | ⏳ فارغ |
| `الغلاف/` | غلاف 1200×630 (حراج/تويتر) + 1080×608 (فيسبوك) | ⏳ فارغ |
| `الصورة-المصغرة/` | صور مصغرة 1080×1080 للإعلانات | ⏳ فارغ |
| `بطاقة-العمل/` | بطاقة 9×5 سم أمامية وخلفية (CMYK + RGB) | ⏳ فارغ |
| `قوالب-الاعلانات/` | قوالب قابلة للتعديل (طبقات نصية) | ⏳ فارغ |
| `fonts/` | خطوط Cairo / Tajawal المحلية (اختياري) | ⏳ فارغ |

## 2) المقاسات القياسية

| الأصل | المقاس | الصيغة |
|---|---|---|
| صورة إعلان حراج | 1080×1080 | JPG (جودة 85%) |
| غلاف | 1200×630 | JPG/PNG |
| صورة الحساب | 1024×1024 | PNG |
| ستوري عرض | 1080×1920 | JPG |
| بطاقة العمل | 90×50 مم + 3 مم Bleed | PDF (PDF/X) |
| الشعار | متجه بلا مقاس | SVG |

## 3) نظام تسمية الملفات

```
[TYPE]-[SUBJECT]-[VARIANT]-[DATE].[ext]

أمثلة:
logo-main-horizontal-v1.svg
ad-porcelain-60x120-2026-11-01.jpg
cover-store-riyadh-v1.png
```

## 4) نسب الصورة

- بلاطة مفردة: مربع 1:1 مع هامش 12% حولها.
- مشهد استخدام: 4:5 عمودي للسوشيال، 1:1 لحراج.
- لا تُقص زوايا البلاطة أبدًا (توحي بعيب).


## 6) الخطوات التالية لتفعيل الأصول

1. اعتماد الشعار (أو توليده) ورفعه إلى `الشعار/`.
2. تنزيل خطي Cairo و Tajawal واختبار التنسيق العربي.
3. إنشاء قالب إعلان واحد متكرر (Grid 12 عمودًا) ثم توليد بقية الإعلانات منه.
4. تصوير 10 أصناف أساسية كبداية (ملمس + 45° + مشهد).
