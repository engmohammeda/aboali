# إعلان 02 — عرض بورسلان 60×120

**تاريخ النشر المستهدف:** 2026-11-04
**الهدف:** أولى الصفقات المباشرة
**القسم في حراج:** مواد بناء / سيراميك وبلاط

---

## عنوان الإعلان

```
بورسلان 60×120 — الرياض — أسعار جملة وتوصيل فوري
```

## نص الإعلان

```
بورسلان مقاس كبير 60×120 — متوفر الآن بالرياض

■ المواصفات:
• المقاس: 60 × 120 سم
• النوع: بورسلان كامل التلبيد (Full Body)
• الملمس: مطفي / لامع (حسب الصنف)
• الاستخدام: أرضيات مجالس، مداخل، صالات، جدران
• مقاومة الانزلاق: [R9 / R10 — حسب الصنف]
• المنشأ: [إسباني / هندي / صيني — حدَّد بدقة]
• الدرجة: أولى

■ السعر:
• [سعر] ر.س / م² — للكميات من [X] م²
• سعر أقل للكميات الكبيرة (جملة للمقاولين)

■ التوصيل والتركيب:
• توصيل داخل الرياض: [مشمول / رسوم حسب الحي]
• تركيب بإشراف: متاح (سعر منفصل حسب المساحة)
• استبدال أي بلاطة تالفة عند التسليم

■ احسب كميتك بسهولة:
المساحة (م²) ÷ (0.6 × 1.2 = 0.72) = عدد البلاطات
ثم أضف 10% هدر للقص والفواصل.
محتاج مساعدة؟ أرسل لي المساحة وأحسبها لك.

📩 واتساب: [الرابط]
📞 [الرقم]
📍 الرياض — حي [الحي]
🕘 ساعات العمل: [..]

الصور من المخزون الفعلي — ولو حاب تشوف الملمس على الطبيعة، المعرض مفتوح.
```

## قائمة المرفقات

- [ ] غلاف: البلاطة + شارة "60×120"
- [ ] ماكرو للملمس
- [ ] لقطة 45° بجانب مرجع مقاس
- [ ] مشهد مجلس/مدخل
- [ ] صورة السعر مكتوب على شريط نحاسي
