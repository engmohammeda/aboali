# التذكيرات وسير العمل

## 1) التذكيرات اليومية

| الوقت | المهمة | الوقت المستغرق |
|---|---|---|
| 9:00 ص | فتح الواتساب + الرد على كل الرسائل المعلقة | 15 د |
| 9:15 ص | مراجعة إعلانات حراج (توفر/سعر) | 10 د |
| 1:00 م | رد سريع + متابعة ثانية للمهتمين (24 س) | 10 د |
| 8:00 م | نشر/تحديث محتوى اليوم حسب الجدول | 20 د |
| 10:00 م | تسجيل محادثات اليوم وأسباب عدم الإغلاق | 10 د |

## 2) مهام دورية

- **كل سبت:** تحديث كل إعلانات حراج + مراجعة الأرقام + قرارات.
- **كل أول شهر:** تحديث الأسعار من الموردين + مراجعة الكلمات المفتاحية.
- **كل 3 أشهر:** مراجعة التموضع والهوية (هل الرسالة تعمل؟).

## 3) سير عمل الإعلان (Workflow)

```
فكرة → نص (نسخة من القالب) → تجهيز الصور → قائمة التحقق → نشر
   → رد فوري → متابعة بعد 24 س → تسجيل النتيجة → قرار (تعديل/إيقاف)
```

## 4) سير عمل العميل

1. **رسالة واتساب** → رد قالبي فوري (خلال 15 د).
2. **تأهيل:** مساحة + مقاس + استخدام + حي.
3. **عرض:** 2–3 بدائل + السعر + التوصيل + صور ملمس.
4. **تأكيد:** الكمية والسعر وموعد التسليم.
5. **تنفيذ:** تجهيز + فحص قبل التسليم + توصيل + استلام الدفعة.
6. **متابعة:** رسالة بعد يومين + طلب تقييم + عرض العميل المتكرر.

## 5) ملف العميل المحتمل (تسجيل بسيط)

| الحقل | مثال |
|---|---|
| الاسم | أبو سالم |
| المصدر | حراج / واتساب / إحالة |
| الحاجة | ترميم حمامين |
| المساحة | 22 م² |
| المقاس | جدران 30×60 |
| المرحلة | عرض مرسل / بانتفظ / ملغي |
| سبب الخسارة | سعر / توفر / تردد / لا رد |

## 6) قواعد الانضباط

- **لا ترد على السعر وحدك** — اربط السعر بالجودة والخدمة.
- **لا تعد بشيء غير متأكد منه** (موعد توصيل، توفر صنف).
- **سجّل كل خسارة بسببها** — بيانات الخسارات أهم من بيانات النجاح.
- **اطلب التقييم دائمًا** — تقييم حراج/واتساب أصل تجاري.
