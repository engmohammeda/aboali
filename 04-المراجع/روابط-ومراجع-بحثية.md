# روابط ومراجع

## 1) منصات النشر والبيع

| المرجع | الرابط | الاستخدام |
|---|---|---|
| حراج — الموقع الرئيسي | https://haraj.com.sa | النشر الأساسي |
| واتساب للأعمال | https://business.whatsapp.com | رد آلي + كتالوج |
| Google Business Profile | https://business.google.com | الظهور في البحث المحلي |
| إنستقرام للأعمال | https://business.instagram.com | المحتوى البصري |

## 2) مراجع فنية (السيراميك والبورسلان)

| المرجع | الاستخدام |
|---|---|
| الهيئة السعودية للمواصفات والمقاييس (SASO) | التحقق من المواصفات القياسية للبلاط |
| الكود السعودي للبناء (SBC) | متطلبات الأرضيات والجدران والسلامة |
| تصنيف مقاومة الانزلاق (R-values / DIN 51130) | اختيار بلاط الحمامات والمسابح |
| معامل امتصاص الماء (Water Absorption) | التفريق بين سيراميك وبورسلان |
| PEI (مقاومة التآكل) | اختيار أرضيات المناطق عالية الحركة |

> ⚠️ تحقق من روابط الهيئات الرسمية قبل الاعتماد؛ قد تُحدَّث الروابط.
> لا تذكر شهادات أو مواصفات في الإعلانات دون مستند من المورد.

## 3) مراجع التسويق والمحتوى

| المرجع | الاستخدام |
|---|---|
| Google Trends (السعودية) | معرفة موسمية البحث عن السيراميك |
| إحصاءات حراج الداخلية | أداء الإعلان |
| Meta Insights | أداء المحتوى البصري |

## 4) قائمة تحقق قانونية/تجارية

- [ ] سجل تجاري ساري (إن كنت تبيع بشكل منظم).
- [ ] فاتورة ضريبية (ضريبة القيمة المضافة).
- [ ] سياسة استبدال مكتوبة ومعلنة.
- [ ] بيانات تواصل صحيحة وقابلة للتحقق (تحرّمك من إعلانات وهمية).

## 5) مسرد المصطلحات

| المصطلح | المعنى |
|---|---|
| بورسلان كامل التلبيد (Full Body) | بلاط متجانس اللون في عمقه، أعلى متانة |
| سيراميك مطلي (Glazed) | طبقة مزجج علوية، تشكيلة ألوان أوسع |
| R10 / R11 | تصنيف مقاومة الانزلاق (الأعلى = أكثر خشونة) |
| PEI IV / V | تصنيف مقاومة التآكل للأرضيات عالية الحركة |
| Rectified | حواف مصنّعة بدقة تسمح بفواصل رقيقة جدًا |
| Haag / الهدر | نسبة زيادة الكمية للقص والفواصل (عادة 10%) |
