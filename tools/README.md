# أداة إضافة الاسم ورقم الهاتف أسفل صور الإعلانات

`add_footer.py` — تضيف **نصّين فقط** أسفل كل صورة إعلان: **اسم النشاط + رقم الهاتف**.
لا شعارات، لا أسعار، لا عناوين، لا أي نصوص أخرى.

## التثبيت

```bash
pip install pillow
```

> الخط العربي: تبحث الأداة تلقائيًا عن `Tajawal-Bold.ttf` في `01-اصول-الهوية/fonts/`،
> وإن لم تجده استخدمت أي خط عربي متاح في النظام. يمكنك تمريره يدويًا بـ `--font`.

## الاستخدام السريع

```bash
# صورة واحدة (تُحفظ بجانب الأصل باسم photo_ad.jpg)
python tools/add_footer.py photo.jpg

# مجلد كامل → مجلد منفصل
python tools/add_footer.py ./raw-images --out ./ready

# كل الصور بامتداد معيّن
python tools/add_footer.py *.jpg --out ./ready
```

## الأوضاع

| النمط | ماذا يفعل | متى تستخدمه |
|---|---|---|
| `overlay` (الافتراضي) | شريط فوق أسفل الصورة | الأسرع، يحفظ مقاس الصورة كما هو |
| `band` | يمدّ الصورة للأسفل بشريط مستقل | عندما لا تريد تغطية أي جزء من الصورة |

```bash
python tools/add_footer.py ./raw --mode band --bg "#1F4E79"
```

## لوحات الألوان الجاهزة

| اللوحة | الخلفية | الاسم | الرقم |
|---|---|---|---|
| `navy` (افتراضي) | `#1F4E79` | أبيض | ذهبي `#C9A227` |
| `terra` | `#B4552D` | أبيض | `#FFE2A8` |
| `dark` | `#2B2B2B` | أبيض | ذهبي |
| `light` | `#EFE7DA` | كحلي | تراكوتا |
| `sand` | `#F8F4EE` | فحمي | تراكوتو |

```bash
python tools/add_footer.py ./raw --palette terra
```

## كل الخيارات

| الخيار | الافتراضي | الوظيفة |
|---|---|---|
| `--name` | أبو عمر للسيراميك والبورسلان | اسم النشاط |
| `--phone` | 0566743293 | رقم الهاتف |
| `--out` | بجانب الأصل | مجلد الإخراج |
| `--font` | تلقائي | مسار ملف `.ttf` |
| `--palette` | `navy` | لوحة الألوان |
| `--mode` | `overlay` | `overlay` أو `band` |
| `--bg` | — | لون خلفية HEX يتجاوز اللوحة |
| `--height` | `0.12` | ارتفاع الشريط كنسبة من ارتفاع الصورة |
| `--quality` | `92` | جودة JPG |
| `--suffix` | `_ad` | لاحقة اسم الملف الناتج |
| `--format` | — | تحويل الصيغة: `jpg` / `png` / `webp` |
| `--dry-run` | — | تجربة بلا حفظ |

## كيف تتعامل الأداة مع المقاسات المختلفة؟

- **صف واحد**: الاسم يمينًا (RTL) والرقم يسارًا — وهو الشكل الافتراضي.
- **تصغير ذكي**: إن ضاق العرض، يُصغّر الخط تدريجيًا حتى **72%** فقط.
- **صفّان**: إن لم يتّسع، ينتقل تلقائيًا لوضع الصفّين (الاسم أعلى، الرقم تحته) بدل خط غير مقروء.
- **حدود الأمان**: الشريط لا يتجاوز 35% من ارتفاع الصورة، والحد الأدنى 64 بكسل.
- **الصور الصغيرة**: تعمل حتى 320×240 بلا مشاكل.
- **EXIF**: يُصحَّح اتجاه الصورة تلقائيًا (صور الجوال).
- **الشفافية**: يدعم PNG الشفاف ويحفظه، أو تحويله إلى JPG.

## أمثلة جاهزة لمشروعنا

```bash
# صور الإعلان الأول بمقاس حراج 1080×1080
python tools/add_footer.py 02-الاعلانات/صور-الاعلانات --out 02-الاعلانات/جاهزة-للنشر

# شريط تراكوتا بنحافة أقل
python tools/add_footer.py 02-الاعلانات/صور-الاعلانات --palette terra --height 0.10
```

## ملاحظات

- الأداة **لا تعدّل** الصورة الأصلية أبدًا — الإخراج في ملف جديد يحمل لاحقة `_ad`.
- الملفات التي تنتهي بـ `_ad` تُتجاهل تلقائيًا عند تمرير مجلد (لمنع المعالجة المزدوجة).
- البيانات الافتراضية (الاسم/الرقم) في أعلى ملف `add_footer.py` داخل قاموس `DEFAULTS` — عدّلها مرة واحدة.
