# أدوات المشروع — أبو عمر للسيراميك والبورسلان

| الأداة | الوظيفة |
|---|---|
| `add_footer.py` | إضافة **الاسم + رقم الهاتف** فقط أسفل الصور بهوية المشروع (أسود + ذهبي) |
| `haraj_optimizer.py` | تحضير الصور لحراج بأعلى جودة ممكنة + قياس الجودة بالأرقام |

pip install -r tools/requirements.txt      # pillow (إلزامي) + numpy/pillow-heif (اختياريان)

## 1) `add_footer.py` — العلامة المائية

```bash
python tools/add_footer.py photo.jpg                        # ذهبي فاخر + توهّج
python tools/add_footer.py ./صور --out ./جاهزة               # مجلد كامل
python tools/add_footer.py a.jpg --palette goldbar          # شريط ذهبي ونص أسود
python tools/add_footer.py a.jpg --mode band --height 0.10  # شريط مستقل لا يغطي الصورة
python tools/add_footer.py a.jpg --no-glow --palette onyx    # بلا توهّج
```

**اللوحات المتاحة:** `gold` (افتراضي) • `goldbar` • `onyx` • `navy` • `terra` • `dark` • `light` • `sand`

**اللوحة الافتراضية `gold`** مطابقة للهوية:
`#0B0906` خلفية • `#FBEBC7` الاسم • `#EACEA5` الرقم • فاصل متدرّج `#5C482F → #FBEBC7` • توهّج `#B88650`.

**ذكاء التخطيط:** صف واحد → تصغير حتى 72% → صفّان تلقائيًا للأسماء الطويلة.
**حماية:** الشريط ≤ 35% من ارتفاع الصورة • يعمل حتى 320×240 • تصحيح EXIF • دعم PNG الشفاف.

## 2) `haraj_optimizer.py` — محسّن حراج

### لماذا تنخفض الجودة أصلًا؟
حراج يعيد ترميز كل صورة ترفعها ويصغّرها. إن رفعت صورة كبيرة أو بملف ألوان غريب
أو بحدّة منخفضة، فالنتيجة بعد إعادة الترميز تكون ناعمة/باهتة. الحل ليس "رفع جودة أعلى"
فقط، بل **تهيئة الصورة لتنجو من إعادة الترميز**.

### ما تفعله الأداة (7 مراحل)

| # | المرحلة | الفائدة |
|---|---|---|
| 1 | تصحيح اتجاه EXIF | يمنع الصور المقلوبة |
| 2 | تحويل إلى **sRGB** | يمنع تغيّر/بهتان الألوان بعد الرفع |
| 3 | تصغير ذكي **LANCZOS** (بلا تكبير) | تفاصيل أنظف من التصغير الافتراضي |
| 4 | حدّة تكيّفية **UnsharpMask** | تعوّض التنعيم القادم من الضغط |
| 5 | ترميز **4:4:4 + progressive + optimize** | أهم إعداد: لا تقليل لعيّنات الألوان |
| 6 | ضبط الجودة تلقائيًا لميزانية الحجم | أعلى جودة ممكنة بلا تجاوز الحد |
| 7 | قياس **PSNR + SSIM + الحدة** | تعرف بالأرقام ماذا حدث لصورتك |

### الإعدادات الجاهزة

| الإعداد | أقصى ضلع | الجودة | الحدّة | مناسب لـ |
|---|---|---|---|---|
| `haraj` (افتراضي) | 2048 | 92 | 1.0 | الاستخدام العام — أفضل توازن |
| `max` | 2560 | 95 | 1.15 | ملمس البلاط والنقوش الدقيقة |
| `balanced` | 1800 | 90 | 0.95 | حجم أصغر بجودة عالية |
| `lite` | 1400 | 86 | 0.85 | صور كثيرة/اتصال بطيء |

### أمثلة

```bash
# الأساسي
python tools/haraj_optimizer.py ./صور-خام --out ./جاهزة-للحراج

# أقصى تفاصيل + علامة مائية ذهبية
python tools/haraj_optimizer.py ./صور-خام --preset max --footer --out ./جاهزة-للحراج

# حد حجم 900 كيلوبايت
python tools/haraj_optimizer.py ./صور-خام --preset balanced --max-kb 900

# دفعة كبيرة + تقارير
python tools/haraj_optimizer.py ./صور-خام --jobs 4 --report report.csv --json report.json

# تجربة بلا حفظ
python tools/haraj_optimizer.py ./صور-خام --dry-run
```

### كيف تقرأ الأرقام؟

| المقياس | المعنى | القيمة الجيدة |
|---|---|---|
| **PSNR** | الفرق الرياضي بين الأصل والناتج | ≥ 38 dB ممتاز • ≥ 35 جيد |
| **SSIM** | التشابه الإدراكي (أقرب لعين الإنسان) | ≥ 0.98 ممتاز • ≥ 0.95 جيد |
| **الحدّة** | نسبة تحسّن تباين الحواف | +30% إلى +60% طبيعي |
| **نسبة الحجم** | حجم الناتج ÷ الأصل | 15–40% طبيعي لصور PNG/الجوال |

### نصائح عملية لحراج

1. ارفع **1080×1080** للإعلان المربع و**1200×900** كحد أدنى — لا أكثر من 2048.
2. لا ترفع ملفات PNG كبيرة؛ حوّلها إلى JPG بـ 4:4:4 (الأداة تفعل ذلك).
3. تجنّب التكبير: صورة صغيرة مكبّرة تبدو مشوّشة أكثر من صورة صغيرة واضحة.
4. استخدم `--preset max` فقط للصور التي فيها **ملمس/نقش** مهم (بورسلان، رخام).
5. طبّق العلامة المائية **قبل** الرفع لا بعده.
6. احفظ دائمًا نسخة أصلية خارج مجلد `جاهزة-للحراج`.

### سلوك الأمان

- لا يعدّل الأصل أبدًا — يخرج في `جاهزة-للحراج/` أو `--out`.
- يتجاهل أي ملف منتهٍ بـ `_haraj` أو الموجود داخل `جاهزة-للحراج` (منع المعالجة المزدوجة).
- لا يُنزل الجودة تحت `min_quality` مهما كان حجم الملف — بل يُصغّر الأبعاد بدلًا من ذلك.
